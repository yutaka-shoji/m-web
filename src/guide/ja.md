# 使い方

m-web は、屋内温熱環境計測機器 **M-Logger** を PC のブラウザから Bluetooth で操作し、複数台の計測値を同時に表示・記録するためのアプリです。インストールは不要で、データはすべてこのブラウザの中に保存されます。

## できること

- 複数台の M-Logger に同時に接続し、乾球温度・相対湿度・グローブ温度・風速・照度・CO₂ 濃度をライブ表示する
- 平均放射温度（MRT）と PMV・PPD を計算して表示する
- 計測値を PC（このブラウザ）に記録し、CSV でダウンロードする
- M-Logger 本体のフラッシュメモリに記録されたデータを Bluetooth で読み出し、CSV にする
- 計測間隔・開始時刻・補正係数・名前の変更、CO₂ センサの校正、本体データの消去

## 動作環境

| 項目 | 内容 |
|---|---|
| ブラウザ | PC 版の **Google Chrome** または **Microsoft Edge**（最新版）。Safari・Firefox・スマートフォンは非対応です |
| PC | Bluetooth（Bluetooth Low Energy）を備えた Windows・macOS・ChromeOS の PC |
| 同時に接続できる台数 | PC の Bluetooth アダプタ次第です。目安は 5〜7 台（下の「機器をつなぐ」を参照） |
| M-Logger | **v4 以降**（本体に USB Type-C ポートがある機器）。v3 以前の機器には対応していません |
| 接続方式 | HTTPS で公開されたページ、または開発時の localhost |

M-Logger は v4 でハードウェアが大きく改められ、USB ポートからファームウェアを更新できるようになりました。このアプリは v4 以降の通信方式で動くため、v3 以前の機器は現在使えません。

macOS では、初めて使うときに「Google Chrome が Bluetooth の使用を求めています」と表示されることがあります。**許可** を選んでください（あとから変更するには「システム設定 > プライバシーとセキュリティ > Bluetooth」）。

## 準備

1. M-Logger の電源を入れます（緑の LED が 1 秒ごとに点滅します）。
2. PC から 10 m 以内に置きます。壁や金属で電波が弱まることがあります。
3. スマートフォンのアプリなど、**ほかの端末と接続していない** ことを確認します。M-Logger が同時に接続できるのは 1 台の親機だけです。

時刻合わせは接続時に自動で行います（記録中の機器の時計は変更しません）。

## 機器をつなぐ

1. ダッシュボードの **「M-Logger を追加」** を押します。
2. ブラウザの選択画面に周囲の機器が表示されるので、接続したいものを選んで **「ペア設定」**（または「接続」）を押します。
3. 認証（約 1.5 秒）と設定の読み込みが終わると、カードに機器名と電池電圧が表示されます。
4. 複数台つなぐときは、1〜3 を繰り返します。接続済みの機器は一覧に出ません。

同時に接続できる台数は、PC の Bluetooth アダプタ（とそのドライバ・OS）の仕様で決まり、公表されていないことがほとんどです。一般的な PC では **5〜7 台** が目安です。マウス・キーボード・イヤホンなど、ほかの Bluetooth 機器も同じ枠を使います。台数を増やしたときに接続できない、または切れやすくなる場合は、台数を減らすか、別の PC に分けてください（動作確認: macOS・Apple Silicon の PC で 3 台）。

選択画面の機器名は「MLogger_xxxx」のほか、**「XBee3 Zigbee」** と表示されることがあります（Mac で一度接続した機器は、OS が無線モジュールの名前を覚えるため）。どれを選んでも、接続後に正しい機器名がカードに表示されます。

接続が切れた場合は自動で再接続を繰り返します（記録中・読み出し中は成功するまで、それ以外は 10 分まで）。

### 「見つかりません」と表示されたら

接続してから数分以上たって切れた場合、ブラウザがその機器を見失うことがあります。特に macOS の Chrome は、電波を受けていない機器を約 3 分で内部の一覧から外すため、自動の再接続では戻りません。このときカードは **「見つかりません」** になります。

1. 機器の電源と、PC との距離を確かめます。
2. カードかダッシュボード上部の **「探して再接続」** を押します。
3. 選択画面にその機器が出たら選びます。選択画面が周囲を探すことで、ほかに見失っていた機器もまとめて再接続されます。

> Chrome で `chrome://flags/#enable-experimental-web-platform-features`（Experimental Web Platform features）を有効にすると、見失った機器も電波を受け取りしだい自動で再接続します。実験的な機能のため、既定では無効です。

> 機器が手元になくても、**「デモ機で試す」** で画面の操作を確かめられます。デモ機の値は架空のデータです。

## ライブ表示と値の見方

カードの **「ライブ表示」** を押すと、機器が計測を始め、値が届くたびに表示が更新されます。複数台なら **「すべてライブ表示」** が便利です。ライブ表示は記録を伴いません。保存するには「記録を開始」してください（次の節）。

| 表示 | 意味 |
|---|---|
| 数値 | 最新の計測値。計測間隔が長い項目は、次の値が届くまで前回の値を表示します |
| — ウォームアップ中 | プローブの立ち上がり中です。温湿度・CO₂ は計測開始から約 25 秒、風速は約 10 秒で表示されます |
| — 計測オフ | 計測設定でその項目が無効になっています |
| — プローブ未接続 | プローブから応答がありません。接続を確認してください |
| 薄い表示 | しばらく新しい値が届いていません |

CO₂ 濃度は、電源オフや計測停止が 3 時間を超えた後、安定するまで 1 時間程度かかることがあります（ファームウェア 4.0.1 以降は自動で立ち上げ処理を行います）。

### MRT・PMV・PPD

- **MRT（平均放射温度）** は、グローブ温度・乾球温度・風速から ISO 7726 の式で求めます。M-Logger のグローブ（直径 38 mm、放射率 0.95）を前提とし、自然対流と強制対流のうち大きい方の熱伝達率を使います（公式アプリと同じ方法です）。
- **PMV・PPD** は ISO 7730 の方法で求めます。ダッシュボードの **「温熱指標の条件」** で着衣量（clo）と代謝量（met）を指定してください。既定値は 1.0 clo・1.1 met です。
- 乾球温度・相対湿度・グローブ温度・風速がそろうまで、またウォームアップ中やプローブ未接続の間は「—」と表示します。風速を計測していない機器では、設定画面で **仮定風速** を指定すると計算できます（その場合は「風速は仮定値」と表示されます）。
- 条件が ISO 7730 の適用範囲（気温 10〜30 ℃、MRT 10〜40 ℃、風速 0〜1 m/s、水蒸気圧 0〜2700 Pa、代謝量 0.8〜4 met、着衣量 0〜2 clo、PMV −2〜+2）を外れると、値に **「範囲外」** の印が付きます。値は参考として扱ってください。

### グラフ

カードの下に、項目ごとに全機器を重ねたグラフを表示します。期間（10 分〜24 時間・すべて）を切り替えられ、グラフ上をドラッグすると拡大、「ライブに戻る」で元に戻ります。マウスを重ねると、その時刻の全機器の値が表示されます。グラフはこのページを開いてからの値（最大 20 万点 × 台数）を表示します。それ以前の記録はデータ画面から CSV で取り出せます。

## 記録する

1. ダッシュボード上部の記録欄で、必要なら **記録名** を入力します。空欄なら `2026-11-07_1830` のように開始日時の名前が付きます（書き出すファイル名にも使われます）。
2. **「本体のフラッシュにも保存（推奨）」** を確認します。
3. **「記録を開始」** を押します。接続中のすべての機器が計測を始め、値がこのブラウザに保存されます。
4. 終了するときは **「停止」** を押します。「機器側の記録も停止する」を選ぶと、電池の消耗を防げます。

- 記録中に接続した機器は、自動で記録に加わります。
- **本体にも保存** を選ぶと、PC との接続が切れても機器側で記録が続き、再接続後は自動で PC への保存も再開します（「見つかりません」になった機器は、「探して再接続」で戻すまで PC への保存が止まります）。あとから本体データを読み出せば欠けた部分を補えます。ただし Bluetooth 送信を続けるため、電池の消耗は早くなります。数日にわたる計測では USB 給電をおすすめします。
- **本体に保存しない** 場合、接続が切れると機器側の計測も止まります（ファームウェアの仕様）。再接続すると、このアプリが自動で計測を再開します。
- ページを閉じたり再読み込みしたりすると、接続はすべて切れます。記録中に閉じようとすると確認が表示されます。再読み込み後は「前回の記録は中断されています」と表示され、**「続きを記録」** で同じ記録に追記できます。

## データと CSV

**データ** 画面に、これまでの記録が一覧表示されます。

- 1 台の記録は CSV、複数台の記録は機器ごとの CSV と `session.json`（機器情報と計算条件）をまとめた ZIP でダウンロードします。
- 「1 つの CSV にまとめる（縦持ち）」を選ぶと、先頭に `device`, `hardware_id` 列が付いた 1 ファイルになります。
- MRT・PMV・PPD は、ダウンロード時の温熱条件（着衣量・代謝量）で計算し直します。

### CSV の列

| 列 | 内容 | 単位 |
|---|---|---|
| `datetime` | 計測時刻。機器のタイムスタンプを PC のタイムゾーンで表し、末尾に UTC との時差を付けます（例: `2026-11-07 18:00:00+09:00`） | — |
| `unix_time` | 同じ時刻の UNIX 秒（UTC） | s |
| `t_dry[C]` | 乾球温度 | °C |
| `rh[%]` | 相対湿度 | % |
| `t_glb[C]` | グローブ温度 | °C |
| `velocity[m/s]` | 風速 | m/s |
| `illuminance[lx]` | 照度 | lx |
| `co2[ppm]` | CO₂ 濃度 | ppm |
| `mrt[C]` | 平均放射温度（算出値） | °C |
| `pmv` | PMV（算出値） | — |
| `ppd[%]` | PPD（算出値） | % |
| `velocity_voltage[mV]` | 風速プローブ電圧（診断用・選択時のみ） | mV |

- 空欄は「その時刻には計測していない」ことを表します（項目ごとに計測間隔が異なるため）。
- 値は機器が送った精度のまま書き出します。
- 文字コードは UTF-8（BOM 付き）なので、Excel で開いても文字化けしません。

## 本体データの読み出し

カードの **「詳細」** →「本体データ（フラッシュ）」で、M-Logger 本体に記録されたデータを読み出せます。

- 件数と所要時間の目安が表示されます。転送は約 2.4 kB/秒で、1 万件で約 1.5 分、60 秒間隔の 1 か月分（約 4.3 万件）で約 7 分です。
- 記録中の機器からは読み出せません。読み出しを押すと、記録を停止するか確認します。
- 途中で中止したり接続が切れたりしても、**「続きから読み出す」** で 1000 件単位の区切りから再開できます。
- 完了したら **「CSV を保存」** を押します（列は上と同じで、値は本体の記録精度です）。データ画面からもダウンロードできます。
- 本体の時計が電源投入時にリセットされていた期間を含む場合など、時刻が前後することがあります。CSV は記録された順のまま書き出します。

## 機器の詳細設定

「詳細」パネルでは次の操作ができます。変更は機器に送信して初めて反映されます。

- **計測設定**: 温湿度・グローブ温度・CO₂（まとめて 1 つ）、風速、照度のそれぞれについて、計測の有無と間隔（1〜86400 秒）、開始時刻。不要な項目をオフにすると電池が長持ちします。特に風速は消費電力が大きい項目です。
- **補正係数**: 補正後の値 = a × 計測値 + b。機器内で適用され、記録値に反映されます。現行ファームウェアでは風速の補正は記録値に反映されないため、変更できないようにしています。
- **CO₂ 校正**: 外気など濃度が分かっている環境に置いて実行します（屋外の大気はおよそ 420 ppm）。基準濃度での校正は約 35 秒、工場出荷時の初期化を伴う校正は約 12 時間かかり、その間は計測できません。記録中は実行できません。
- **名前の変更**: 20 バイトまで（日本語は 1 文字 3 バイト）。一覧の絞り込みに使われるため「MLogger_」で始まる名前を推奨します。新しい名前が Bluetooth の一覧に表示されるのは、機器を再起動した後です。
- **本体のデータを消去**: 確認のため機器名の入力が必要です。元に戻せないので、必要なデータは先に読み出してください。

## 長時間計測のコツ

- **PC をスリープさせない**: スリープすると Bluetooth 接続が切れます。電源設定でスリープを無効にしてください（ノート PC はふたを閉じない）。
- **ウィンドウを表示したままにする**: このアプリは記録中・読み出し中に画面の消灯を防ぎます（表示中のみ）。ほかのタブに切り替えても受信と保存は続きますが、ブラウザの省電力機能が働かないよう、このタブは閉じたり破棄したりしないでください。
- **切断に備える**: 無人で長時間計測するときは「本体にも保存」を選んでください。いったん切れた機器が「見つかりません」のまま戻らなくても、本体には記録が続いているので、あとから本体データを読み出して補えます。
- **電池**: 本体にも保存しながら PC で記録すると、Bluetooth 送信のぶん電池の消耗が早くなります。電池電圧はカードと詳細パネルで確認でき、低下すると朱色で表示されます。数日以上の計測では USB 給電が確実です。
- **ブラウザの保存容量**: データ画面で使用量を確認できます。不要になった記録は CSV で保存してから削除してください。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 選択画面に機器が出ない | 電源と LED の点滅、10 m 以内か、スマートフォンなど別の端末と接続していないか。接続済みの機器は表示されません。PC の Bluetooth がオンか |
| 「XBee3 Zigbee」としか表示されない | 正常です。選ぶと接続後に正しい名前が表示されます |
| 「見つかりません」と表示される | ブラウザが機器を見失っています。電源と距離を確かめて「探して再接続」を押し、選択画面で機器を選んでください |
| 接続できない・認証に失敗する | 機器の電源を入れ直してから再度追加してください。Windows では Bluetooth のオン・オフで改善することがあります |
| 「非対応（v3 以前）」と表示される | v3 以前の機器です。このアプリは v4 以降（USB Type-C ポートがある機器）にのみ対応しています |
| 値が「—」のまま | 計測開始直後のウォームアップ中か、その項目が計測オフになっていないか（詳細 → 計測設定） |
| MRT・PMV が「—」 | 風速がオフの機器では計算できません。設定画面で仮定風速を指定できます |
| 頻繁に切れる | 距離を縮め、障害物を減らしてください。同時に接続する台数を減らすと安定することがあります |
| 記録が途中で止まった | 「本体に保存しない」記録は、接続が切れると機器側でも計測が止まります。アプリは再接続後に自動で再開しますが、切断中の値は残りません |

## データとプライバシー

- 計測データ・設定はすべてこのブラウザの中（IndexedDB・localStorage）に保存され、外部のサーバーには送信されません。
- ブラウザの「閲覧履歴データの削除」でサイトデータを消すと、記録も消えます。必要なデータは CSV で保存してください。
- ほかの PC やブラウザとは自動で共有されません。
